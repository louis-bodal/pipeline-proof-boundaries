Resources referenced by external systems must keep a stable identity
across deployments unless an explicit change is intended.

## Example — Stable resource name

```bicep
param environment string = 'prod'

resource app 'Microsoft.Web/sites@2023-12-01' = {
  name: 'demo-app-${environment}'
  location: resourceGroup().location
}
```

## Example — Pipeline blocked on unexpected identity change

```bash
EXPECTED_APP_NAME="demo-app-prod"
ACTUAL_APP_NAME=$(az webapp show \
  --resource-group "$RESOURCE_GROUP" \
  --name "$EXPECTED_APP_NAME" \
  --query name \
  --output tsv)

if [ "$ACTUAL_APP_NAME" != "$EXPECTED_APP_NAME" ]; then
  echo "Unexpected resource identity"
  exit 1
fi

echo "Resource identity verified: $ACTUAL_APP_NAME"
```
