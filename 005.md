
Critical conditions must be explicitly verified before the pipeline
is allowed to continue.

A failed verification must stop the execution path that depends on it.

## Example — Artifact existence verified

```bash
ARTIFACT="$BUILD_ARTIFACTSTAGINGDIRECTORY/application.zip"

if [ ! -f "$ARTIFACT" ]; then
  echo "Artifact not found"
  exit 1
fi

echo "Artifact verified"
````

## Example — Deployment allowed only after validation

```yaml
jobs:
- job: Validate
  steps:
  - script: |
      test -f "$(Build.ArtifactStagingDirectory)/application.zip"
    displayName: "Validate artifact"

- job: Deploy
  dependsOn: Validate
  condition: succeeded()
  steps:
  - script: |
      echo "Deploying verified artifact"
    displayName: "Deploy"
```
