The artifact must be explicitly identified so it can be tracked
and verified throughout the delivery chain.

## Example — Definition
```yaml
- task: PublishPipelineArtifact@1
  inputs:
    targetPath: front/dist/namedproject/browser
    artifact: front-build

- task: DownloadPipelineArtifact@2
  inputs:
    artifact: front-build
    path: $(Pipeline.Workspace)/front-build
```

## Example — Version present or pipeline blocked
```bash
VERSION_FILE="$BUILD_ARTIFACTSTAGINGDIRECTORY/version.txt"

if [ ! -f "$VERSION_FILE" ]; then
  echo "Version not defined for artifact"
  exit 1
fi

VERSION=$(cat "$VERSION_FILE")

if [ -z "$VERSION" ]; then
  echo "Empty artifact version"
  exit 1
fi

echo "Artifact version detected: $VERSION"
```
