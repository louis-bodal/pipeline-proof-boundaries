The artifact must remain unchanged after it has been produced and identified.

Its integrity must be verifiable before it is consumed or deployed.

## Example — Integrity verified

```bash
ARTIFACT="application.zip"
EXPECTED_HASH_FILE="application.zip.sha256"

sha256sum -c "$EXPECTED_HASH_FILE"

if [ $? -ne 0 ]; then
  echo "Artifact integrity check failed"
  exit 1
fi

echo "Artifact integrity verified"
```

## Example — Pipeline blocked on divergence

```bash
EXPECTED_HASH=$(awk '{print $1}' application.zip.sha256)
ACTUAL_HASH=$(sha256sum application.zip | awk '{print $1}')

if [ "$EXPECTED_HASH" != "$ACTUAL_HASH" ]; then
  echo "Artifact hash mismatch"
  exit 1
fi

echo "Artifact hash verified: $ACTUAL_HASH"
```
