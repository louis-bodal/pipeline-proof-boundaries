The artifact must have a unique and unambiguous identity.

Any change that affects the artifact must produce a new identity.

## Example — Version generated from a single source

```bash
VERSION="$(Build.BuildId)"

echo "$VERSION" > "$(Build.ArtifactStagingDirectory)/version.txt"

echo "Artifact version: $VERSION"
```

## Example — Pipeline blocked if version is missing or ambiguous

```bash
VERSION_FILE="$(Build.ArtifactStagingDirectory)/version.txt"

if [ ! -f "$VERSION_FILE" ]; then
  echo "Artifact version not found"
  exit 1
fi

VERSION=$(cat "$VERSION_FILE")

if [ -z "$VERSION" ]; then
  echo "Artifact version is empty"
  exit 1
fi

echo "Artifact identity verified: $VERSION"
```
